# Web Clipper - Chrome Extension

Chrome расширение для извлечения контента веб-страниц и конвертации в Markdown.

## 📦 Установка

### Шаг 1: Скачайте или клонируйте репозиторий

```bash
git clone https://github.com/ВАШ_ЛОГИН/web-clipper.git
```

Или скачайте ZIP архив и распакуйте.

### Шаг 2: Загрузите расширение в Chrome

1. Откройте Chrome и перейдите на `chrome://extensions/`
2. Включите **"Режим разработчика"** (переключатель в правом верхнем углу)
3. Нажмите **"Загрузить распакованное расширение"**
4. Выберите папку `chrome-extension` из этого репозитория
5. Расширение появится в списке

### Шаг 3: Закрепите расширение (опционально)

1. Нажмите на иконку пазла 🧩 в правом верхнем углу Chrome
2. Найдите "Web Clipper" в списке
3. Нажмите на булавку 📌 чтобы закрепить

## 🚀 Использование

### Извлечение контента

1. Откройте любую веб-страницу
2. Нажмите на иконку Web Clipper 📋 в панели расширений
3. Нажмите кнопку **"📋 Clip This Page"**
4. Расширение извлечет основной контент и конвертирует в Markdown
5. Нажмите **"📋 Copy Markdown"** чтобы скопировать результат

### Настройка API (опционально)

Если хотите автоматически отправлять контент на свой сервер:

1. Откройте popup расширения
2. Перейдите на вкладку **"Settings"**
3. Укажите:
   - **API URL** - адрес вашего endpoint
   - **API Key** (опционально) - ключ авторизации
   - Выберите что включать в Markdown (заголовок, URL, дату)
4. Нажмите **"💾 Save Settings"**

### Формат API запроса

Расширение отправляет POST запрос с JSON:

```json
{
  "url": "https://example.com/article",
  "title": "Заголовок статьи",
  "content": "# Markdown контент...",
  "format": "markdown",
  "clippedAt": "2024-01-20T12:00:00.000Z"
}
```

## 🐛 Устранение неполадок

### Расширение не загружается

- Убедитесь что включен "Режим разработчика" в `chrome://extensions/`
- Проверьте что все файлы находятся в одной папке
- Откройте консоль (F12) и проверьте ошибки

### Кнопка не работает

- Откройте popup расширения
- Нажмите F12 чтобы открыть консоль
- Проверьте вкладку Console на наличие ошибок
- Пришлите скриншот ошибок

### Контент извлекается некорректно

- Расширение ищет теги `<article>`, `<main>`, `[role="main"]`
- Если их нет, используется `<body>`
- Некоторые сайты с динамическим контентом могут работать некорректно
