# Web Clipper - Chrome Extension

Chrome расширение для извлечения контента веб-страниц и конвертации в Markdown с помощью Defuddle.

## 🚀 Быстрый старт

### Установка расширения

1. **Скачайте или клонируйте репозиторий**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/web-clipper.git
   ```

2. **Откройте Chrome Extensions**
   - Введите в адресной строке: `chrome://extensions/`
   - Включите **"Режим разработчика"** (справа вверху)

3. **Загрузите расширение**
   - Нажмите **"Загрузить распакованное расширение"**
   - Выберите папку `chrome-extension` из этого репозитория

4. **Закрепите расширение** (опционально)
   - Нажмите на иконку пазла 🧩 в Chrome
   - Найдите "Web Clipper" и нажмите 📌

## 📋 Использование

1. Откройте любую веб-страницу
2. Нажмите на иконку Web Clipper 📋
3. Нажмите **"📋 Clip This Page"**
4. Defuddle извлечёт основной контент и конвертирует в Markdown
5. Нажмите **"📋 Copy Markdown"** чтобы скопировать результат

## ⚙️ Настройка API (опционально)

Если хотите автоматически отправлять контент на свой сервер:

1. Откройте popup расширения
2. Перейдите на вкладку **"Settings"**
3. Укажите:
   - **API URL** - адрес вашего endpoint
   - **API Key** (опционально) - ключ авторизации
   - Выберите что включать в Markdown (заголовок, URL, дату)
4. Нажмите **"💾 Save Settings"**

### Формат API запроса

Расширение отправляет POST запрос с JSON:

```json
{
  "url": "https://example.com/article",
  "title": "Заголовок статьи",
  "author": "Имя автора",
  "published": "2024-01-15",
  "description": "Краткое описание...",
  "content": "# Markdown контент...",
  "format": "markdown",
  "clippedAt": "2024-01-20T12:00:00.000Z"
}
```

## ✅ Возможности

- 🧠 **Умное извлечение контента** через Defuddle
- 📝 **Чистый Markdown** с правильным форматированием
- 📊 **Извлечение метаданных** — заголовок, автор, дата публикации, описание
- 🔗 **Интеграция с API** — отправка клипнутого контента на любой эндпоинт
- 🔑 **Аутентификация** — поддержка Bearer-токена
- ⚡ **Быстро** — извлечение контента происходит локально в браузере
- 🎯 **Удаляет мусор** — реклама, навигация, сайдбары, комментарии

## 🧠 Как работает Defuddle

Defuddle — библиотека извлечения контента от создателя Obsidian (kepano):
- Находит основную область контента с помощью алгоритма скоринга
- Удаляет навигацию, рекламу, сайдбары, футеры, комментарии
- Обрабатывает сноски, блоки кода, математические формулы
- Извлекает метаданные из schema.org, meta-тегов и т.д.
- Конвертирует очищенный HTML в Markdown

## 🐛 Устранение неполадок

### Расширение не загружается
- Убедитесь что включен "Режим разработчика"
- Проверьте что все файлы в папке `chrome-extension`
- Откройте `chrome://extensions/` и проверьте ошибки

### Кнопка не работает
- Откройте popup и нажмите F12
- Проверьте консоль на ошибки
- Убедитесь что вы на обычной веб-странице (не chrome://)

### Контент извлекается некорректно
- Defuddle автоматически находит основной контент
- Некоторые SPA могут работать некорректно
- Проверьте консоль на ошибки
