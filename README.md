# Web Clipper - Chrome Extension

Chrome расширение для извлечения контента веб-страниц и конвертации в Markdown.

## 🚀 Быстрый старт

### Установка расширения

1. **Скачайте или клонируйте репозиторий**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/web-clipper.git
   ```

2. **Откройте Chrome Extensions**
   - Введите в адресной строке: `chrome://extensions/`
   - Включите **"Режим разработчика"** (справа вверху)

3. **Загрузите расширение**
   - Нажмите **"Загрузить распакованное расширение"**
   - Выберите папку `chrome-extension` из этого репозитория

4. **Закрепите расширение** (опционально)
   - Нажмите на иконку пазла 🧩 в Chrome
   - Найдите "Web Clipper" и нажмите 📌

## 📋 Использование

1. Откройте любую веб-страницу
2. Нажмите на иконку Web Clipper 📋
3. Нажмите **"📋 Clip This Page"**
4. Нажмите **"📋 Copy Markdown"** чтобы скопировать результат

## ⚙️ Настройка API (опционально)

1. Откройте popup расширения
2. Перейдите на вкладку **"Settings"**
3. Укажите:
   - **API URL** - адрес вашего endpoint
   - **API Key** (опционально) - ключ авторизации
4. Нажмите **"💾 Save Settings"**

### Формат API запроса

```json
{
  "url": "https://example.com/article",
  "title": "Заголовок статьи",
  "content": "# Markdown контент...",
  "format": "markdown",
  "clippedAt": "2024-01-20T12:00:00.000Z"
}
```

## 🐛 Устранение неполадок

### Расширение не загружается
- Убедитесь что включен "Режим разработчика"
- Проверьте что все файлы в папке `chrome-extension`

### Кнопка не работает
- Откройте popup и нажмите F12
- Проверьте консоль на ошибки
- Пришлите скриншот ошибок
