# Web Clipper - Chrome Extension

Простое расширение для Chrome, которое извлекает контент веб-страницы и конвертирует его в Markdown.

## Установка

### Шаг 1: Скачайте файлы расширения

Скачайте все файлы из этой папки:
- `manifest.json`
- `background.js`
- `popup.html`
- `popup.js`

### Шаг 2: Создайте папку для расширения

Создайте новую папку на вашем компьютере, например:
- Windows: `C:\WebClipper\`
- Mac: `~/WebClipper/`
- Linux: `~/WebClipper/`

### Шаг 3: Скопируйте файлы

Скопируйте все 4 файла (`manifest.json`, `background.js`, `popup.html`, `popup.js`) в созданную папку.

### Шаг 4: Откройте Chrome Extensions

1. Откройте Chrome
2. В адресной строке введите: `chrome://extensions/`
3. Нажмите Enter

### Шаг 5: Включите режим разработчика

В правом верхнем углу страницы включите переключатель **"Режим разработчика"** (Developer mode).

### Шаг 6: Загрузите расширение

1. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked)
2. Выберите папку, куда вы скопировали файлы расширения
3. Нажмите "Выбор папки" (Select Folder)

### Шаг 7: Закрепите расширение (опционально)

1. Нажмите на иконку пазла 🧩 в правом верхнем углу Chrome
2. Найдите "Web Clipper" в списке
3. Нажмите на булавку 📌 рядом с ним, чтобы закрепить

## Использование

1. Откройте любую веб-страницу
2. Нажмите на иконку Web Clipper 📋 в панели расширений
3. Нажмите кнопку **"📋 Clip This Page"**
4. Подождите, пока контент будет извлечён
5. Нажмите **"📋 Copy Markdown"** чтобы скопировать результат

## Как это работает

Расширение:
- Извлекает заголовок и URL текущей страницы
- Находит основной контент (article, main, .content и т.д.)
- Удаляет ненужные элементы (реклама, навигация, футер и т.д.)
- Конвертирует HTML в простой Markdown
- Показывает превью и позволяет скопировать результат

## Файлы

- `manifest.json` - конфигурация расширения
- `background.js` - фоновый скрипт
- `popup.html` - интерфейс popup
- `popup.js` - логика popup

## Примечания

- Это упрощённая версия без библиотеки Defuddle
- Конвертация HTML в Markdown базовая
- Для более качественной конвертации можно добавить библиотеку Turndown или Defuddle
